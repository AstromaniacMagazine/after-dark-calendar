    Location and privacy

    Location is optional. Save up to five places in this browser for 30 days only if you opt in; you can clear them at any time. Theme memory is optional too.

    How location and external services work

    Device location needs browser permission. Coordinates go to Open-Meteo for weather and BigDataCloud to name the place; typed searches use Open-Meteo geocoding. Those services receive your IP address. The calendar host and external images also receive ordinary network requests. The magazine site manages its own cookies.

    Rise and set times assume a level horizon, sea-level observer and standard refraction; terrain and weather may change observed times. Open-Meteo terms · BigDataCloud privacy · Magazine privacy policy.
